# Parampara Connect

Parampara Connect is a mobile-first link hub application for "The Parampara Events". It serves as a centralized landing page to connect clients and visitors to various platforms including the official website, Instagram, WhatsApp, location maps, gallery, and appointment bookings.

## Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

## Configuration

To update any URLs or links in the application, simply edit the `src/config/constants.ts` file.
